Hiệu Ứng Đã Được Áp Dụng

  • Glassmorphism Design: Background blur + border gradient
  • Drop Shadow: Ảnh có bóng đổ mượt mà
  • Hover Animation: Scale 1.12x + translateY -8px + shadow tăng
  • Responsive: 200px (mobile) → 240px (tablet) → 280px (desktop)
  • Object-fit: contain: Ảnh không bị méo, giữ tỷ lệ
  • Lazy Loading: Ảnh chỉ tải khi xuất hiện trong viewport
  • Alt Text: Accessibility cho screen reader
  • Fallback Image: Placeholder khi URL lỗi

Hướng Dẫn Sử Dụng

  • Hover chuột vào card để xem hiệu ứng animation
  • Resize trình duyệt để xem responsive design
  • Mở DevTools (F12) để kiểm tra CSS và HTML
  • Chạy SQL script để áp dụng vào hệ thống thực tế
